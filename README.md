Офлайн Android-приложение для тренировочной подготовки к ЕНТ по математике, физике и информатике. Приложение написано на Java 17, минимальная версия Android — API 24. В манифестах нет разрешения на интернет.

## Сборка

Проект использует Android Gradle Plugin 8.7.3, Gradle 8.9 и Android SDK 35. В проект включён Gradle wrapper. Импортируйте папку в Android Studio с установленным Android SDK 35 либо выполните `./gradlew assembleDebug` и `./gradlew test`.

Флаг `enableInformaticsUpdate=true` в `gradle.properties` включает отдельный Gradle-модуль `:update:informatics`. Для сборки ядра без обновления установите `false`.

## Данные предметов

Реестр сканирует `assets/subjects/*/subject.json`. Новый предмет добавляется отдельным каталогом с описанием, банком вопросов и `variants.json`. Данные обновления находятся в `update/informatics/src/main/assets/subjects/informatics/`; assets подключённых Android-модулей объединяются при сборке.

Приложение вопросов содержит `schemaVersion`, `subjectId` и массив `questions`. У каждого вопроса есть уникальный `id`, короткий латинский `topic`, сложность `difficulty` (1–3), `text`, необязательный `code`, четыре `options`, индекс верного ответа `correctIndex`, пояснение `explanation`, `source` и `sourceNote`. Вариант содержит последовательный номер, заголовок и список уникальных ID вопросов. Источник `original` означает вопрос, самостоятельно составленный для этого приложения.

## Принятые допущения и ограничения

- В каждом из трёх предметов создано 10 вариантов по 25 вопросов (250 вопросов на предмет).
- Масив формируется из параметризованных задач и распределён по десяти разделам программы. Это тренировочный черновик, а не редакционно утвержденный банк: многие задачи проверяют базовые вычисления по соответствующей теме и не охватывают весь спектр сложности ЕНТ. 
- Приложение поддерживает выбор фиксированного варианта, случайный тест и тренировку по теме, 35-минутный таймер(Как и на реальном ент), сохранение незавершённой сессии и последних 20 результатов, итоговый балл и разбор.
- Карточки предметов показывают подписи «Вопросы за 2021 год» (математика и физика) и «Вопросы за 2022 год» (информатика) как пользовательские метки наборов, а не как атрибуцию источника. Общая тема DayNight следует системному режиму; добавлена векторная иконка. Перевод интерфейса на казахский язык не добавлен(Потому что вопросов на казахском я в группе не нашёл).
